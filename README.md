# کاتالوگ فارسی سبزکاوشان

وب‌سایت واکنش‌گرا با Vite و JavaScript، بدون نیاز به پایگاه داده یا کلید API. شامل فیلتر و جست‌وجوی فارسی، صفحه مستقل جزئیات با مسیر hash، معرفی حوزه‌های پژوهش و خدمات و بخش ارتباط است.

## اجرای محلی

Node.js 24 و npm لازم است. در پوشه پروژه اجرا کنید:

```sh
npm ci
npm run dev
```

سرور توسعه روی پورت 5173 اجرا می‌شود. برای بررسی نسخه انتشار:

```sh
npm test
npm run build
npm run preview
```

## ویرایش محتوا

اطلاعات شرکت، شماره تماس، ایمیل، نشانی، دسته‌ها و محصولات در `src/data.js` قرار دارند. شماره و ایمیل فعلاً خالی هستند؛ با درج شماره معتبر، دکمه تماس فعال می‌شود. تصاویر در `public/images` تصویرسازی مفهومی هستند، نه تصویر واقعی کالا. تصویر واقعی را جایگزین کنید و مسیر نسبی آن را در داده محصول بنویسید. متن خدمات و معرفی در `src/main.js` و ظاهر در `src/style.css` قابل‌ویرایش است.

تمام محصولات نمونه‌اند. پیش از انتشار تجاری، معرفی شرکت، اطلاعات تماس، تصاویر، مجوزها و هر مشخصه یا ادعای علمی را با اطلاعات رسمی بررسی و جایگزین کنید. سایت در وضعیت فعلی هیچ توصیه مصرف، ترکیب شیمیایی یا ادعای اثربخشی ارائه نمی‌کند. فونت Vazirmatn از Google Fonts دریافت می‌شود؛ اگر دسترسی ممکن نباشد، Tahoma و فونت سیستم استفاده می‌شوند.

## انتشار با GitHub Pages

در تنظیمات مخزن، بخش Settings → Pages، منبع Build and deployment را روی **GitHub Actions** بگذارید. workflow موجود با هر push به main، تست و ساخت را اجرا و خروجی را منتشر می‌کند. نخستین انتشار را می‌توان از Actions → Deploy catalog to GitHub Pages → Run workflow نیز آغاز کرد. پس از موفقیت، نشانی معمول سایت:

https://sorenmaisto63-rgb.github.io/sabzkavashan-catalog/

این نشانی تنها پس از فعال‌سازی Pages و موفقیت deployment قابل استفاده است. مسیرهای hash نیاز به تنظیم بازنویسی سرور ندارند.

## انتشار با میزبان دیگر

در Netlify، Vercel یا میزبان فایل ایستا، فرمان build برابر `npm run build` و پوشه خروجی `dist` است. برای میزبانی در زیرمسیر از `npm run build -- --base=/your-path/` استفاده کنید. اجرای سرور Vite برای میزبانی تولید توصیه نمی‌شود؛ فایل‌های dist را منتشر کنید.
